## 一句话理解本仓库

> 任何 Agent 在这里向我解释世界：先用直觉讲清，再配一张合适的图；
> 长任务住在隔离的文件夹里；产出沉淀进 knowledge/，让初稿越写越像我。

## 核心设计原则（详见各文档）

1. **文件即真相**：`.d2` / `.excalidraw` / `draft-vN.md` 都是可读可 diff 的源文件；画板上的修改可保存回文件。
2. **原生凭据，零仓库**：每个工具用自己的官方登录态，仓库不存任何密钥（[工具与凭据](tools.md)）。
3. **任务隔离**：一个任务一个文件夹，TASK.md 是上下文锚点，不依赖聊天历史（[任务文件夹](tasks.md)）。
4. **风格学习闭环**：博客定稿自动保存「Agent 末版 vs 用户终版」版本对，累积进风格档案（[工作流](workflows.md)）。
