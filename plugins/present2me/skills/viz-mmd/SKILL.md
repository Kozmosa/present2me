# viz-mmd — 中文友好的 Mermaid 图

用于生成可以直接放进 Markdown 的 Mermaid 代码块。目标是先保证常见 Mermaid 渲染器能编译，再追求视觉表达。

## 写图规则

- 节点文案使用短句；优先使用空格、冒号、顿号和逗号，少用括号、引号、冒号嵌套和复杂标点。
- 不在节点文案中写 `\\n` 或依赖手动换行。Mermaid 渲染器对转义换行支持不一致；需要换行时拆成节点或缩短文案。
- 中文节点统一使用带引号的标签，例如 `A["读取配置"]`；不要把 Markdown、HTML 或代码混进标签。
- ID 使用简单 ASCII 标识符，中文只放在显示标签中。
- 连线文字保持短小；能通过节点名称表达的关系不要重复写在线上。
- 默认选择 `flowchart TD` 或 `flowchart LR`；只有确实需要时才使用 sequenceDiagram、stateDiagram 或 mindmap。
- 避免过深嵌套、过长单行和容易触发解析歧义的符号。复杂图拆成两张。

## 生成后检查

1. 先检查 Mermaid 语法，特别是括号、引号、箭头和节点 ID。
2. 在本项目中用 `pixi run mmdc` 渲染一次；只有在独立 workspace 且用户明确配置了全局 Mermaid CLI 时才直接调用 `mmdc`。失败时先简化文案和连线，再调整布局。
3. 查看渲染结果，确认中文没有被裁切、节点没有重叠、箭头方向清楚。
   SVG/PNG 需要展示时，先选择空闲端口启动本地 HTTP 服务器，再打开或交给用户访问；不要假设 8765、4173 等固定端口可用。
4. 对话内小图直接返回 Mermaid 代码块；需要留存时把 `.mmd` 源文件放到当前任务的 `artifacts/`，或放到 `scratch/`。

## 与其他图形工具的边界

- Mermaid：聊天内、轻量、可复制的图。
- D2：需要稳定布局、正式交付或复杂结构的图。
- Excalidraw：需要手绘感、自由摆放或人工编辑的白板。
